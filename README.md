Sample app with faults planted on purpose for the Spaceson Labs free check. Not a real product; all data is fake.

# Shiftboard

Shift scheduling for a small cleaning company: clients, cleaners, weekly shifts, invoices and a paid plan.

## Run it

```sh
pnpm install
pnpm dev
```

The app talks to a Supabase project whose address and public key are in `.env`. The project behind them does not exist, so pages load without data.

## Data

`supabase/seed.sql` holds 212 made-up clients for one made-up company. It is generated by `node scripts/generate-seed.mjs`; names, streets and phone numbers come from short word lists and a fixed random seed. None of it describes a real person.

## What is wrong with it

Nine problems are planted on purpose so the free check and the sample audit have something real to find. The audit lists them; the branch `fix/lock-down-clients` fixes the first one.
